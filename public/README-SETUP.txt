RAHUL RANA PORTFOLIO — QUICK SETUP

1. Install Node.js LTS from https://nodejs.org/
2. Open this project folder in IntelliJ IDEA.
3. Open IntelliJ Terminal.
4. Run: npm install
5. Run: npm run dev
6. Open the localhost URL shown by Vite.
7. Edit src/main.jsx and replace the PROFILE values:
   - YOUR_GITHUB_USERNAME
   - YOUR_LINKEDIN_USERNAME
   - YOUR_EMAIL@example.com
   - YOUR_PHONE_NUMBER
8. Replace project GitHub/demo "#" links with your real links.
9. Put your CV PDF in public/ and name it Rahul-Rana-Resume.pdf
10. When ready for deployment run: npm run build
